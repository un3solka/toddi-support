# Toddi support

Public privacy and support pages for Toddi, a private daily mood check-in for iPhone.

- [Privacy Policy](https://un3solka.github.io/toddi-support/privacy/)
- [Support](https://un3solka.github.io/toddi-support/support/)

The site is static and uses no analytics, cookies, trackers, external fonts, or JavaScript.

## Publishing

GitHub Pages should publish from the `main` branch and the repository root.
